Projects worth a closer look

Personal work, built to chase down questions the day job raised but did not have room to answer.

Mnemo

↗

Tenant-safe conversational memory layer for GTM agents. The hard part of agent memory is not storing things, it is knowing which stored fact is still true, and keeping one customer's facts away from another's. Tenant isolation is a constructor-scoped invariant rather than a query filter, fact conflicts resolve on the write path, and retrieval abstains rather than guessing. Against a naive baseline on a fixed adversarial set: 0/11 to 11/11 passing, cross-tenant leaks 7 to 0.

MemoryTenant IsolationEval HarnessPydantic

GTM Signal Intelligence

↗

Grounded, evaluated revenue intelligence pipeline. Turns raw GTM signals into structured intelligence a RevOps team could trust. Extraction runs through forced tool use against closed schemas, every extracted value carries its own evidence and confidence, answers are cited through hybrid retrieval, and nothing ships without a computed pass/fail gate.

Forced Tool UseHybrid RetrievalPass/Fail GatesRevOps

RIFT

↗

Chaos engineering and reliability testing for tool-using agents. Agent benchmarks test the happy path. Production agents issue duplicate refunds when a confirmation is lost after a successful write. RIFT injects a taxonomy of realistic tool and data failures, then replays a scenario exactly or counterfactually to compare how different prompts and models behave under identical faults.

Chaos EngineeringFault InjectionAgent TestingReplay
